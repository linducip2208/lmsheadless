# Panduan Orang Tua

Untuk peran `parent` di portal Orang Tua.

## 1. Akun & penautan anak

- Akunmu dibuatkan admin dan **ditautkan ke anakmu**. Kamu hanya bisa melihat data anak yang tertaut — tidak ada data siswa lain.
- Bila anak belum muncul, hubungi admin sekolah/lembaga untuk menautkan.

## 2. Yang bisa dipantau

- **Progres belajar**: pelajaran selesai dan kursus yang diikuti per anak.
- **Nilai**: skor kuis dan tugas beserta umpan balik guru.
- **Kehadiran**: rekap hadir/alpa/terlambat/izin per sesi.
- **Pengumuman**: informasi dari sekolah/lembaga dan guru.

## 3. Verifikasi sertifikat

- Setiap sertifikat kelulusan anak punya nomor resmi — siapa pun bisa memeriksanya di halaman `/verify` situs publik.

## Privasi

- Data hanya bisa diakses akun tertaut; sesi web memakai cookie aman dan token berdurasi pendek.
- Bila berganti perangkat, cukup masuk ulang — tidak ada data yang tersimpan permanen di luar akunmu.
